## 本地预览 / Local preview

我在本仓库维护网站源码与内容，使用 HTML、CSS 和 JavaScript，并通过 GitHub Pages 发布。使用 Python 3，在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000/>。静态页面预览无需安装前端依赖；依赖外部服务的功能仍需联网及相应配置。

I maintain the website source and content in this repository and publish it through GitHub Pages. To preview the static pages, run the command above with Python 3 from the repository root. Features backed by external services require network access and their corresponding configuration.
